Questions

Do I need to know how to code?

No. The main path uses the chat assistant you already have and takes about 15 to 30 minutes. There is an optional minimal-code path with an annotated Python sketch if you want to go further.

Which AI tools does it work with?

Any modern chat assistant that supports custom instructions or lets you paste a long first message. The prompts are plain text, so you are not tied to one vendor.

Is an "agent" here fully autonomous?

No. The kit teaches agents as a goal, instructions, tools and a loop that you stay in control of. Blueprints like the Inbox Triage Helper draft replies for you to review rather than sending anything.
