Coding pack #16

"Safe to run?" check

When to use: Before running any command, script or fix you didn't write yourself, including one the AI wrote.

Before I run this, review it for safety:
[PASTE COMMAND / SCRIPT / FIX]
1. Explain in plain English what it will do.
2. Flag anything that: deletes or overwrites files, changes system settings, installs packages, sends data over the network, needs admin/sudo, or downloads and runs code (e.g. curl ... | sh).
3. Rate the risk Low / Medium / High.
4. Tell me how to test it safely first (dry run, backup, sandbox, copy of the data).
Game design pack #5

Scope killer

When to use: Your feature list keeps growing and the deadline doesn't move.

Here's my feature list: [FEATURES]. I have [HOURS] in total.
Be ruthless:
1. Estimate rough hours per feature. Label them as guesses.
2. Mark each feature as core-to-the-fun or nice-to-have.
3. Cut until the total fits with 25% of the time left as buffer.
4. Suggest cheap substitutes for expensive features (e.g. text boxes instead of cutscenes, one looping track instead of a soundtrack).

Pre-mortem

When to use: Before committing to a plan.

Imagine it's [DATE] and my plan to [PLAN] has failed. List the 7 most likely reasons it failed, ranked by likelihood. For each, give one early warning sign and one cheap thing I can do now to prevent it.
