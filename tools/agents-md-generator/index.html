How to use it

  1. Choose your stack. The commands, layout and conventions fill in with common defaults.
  2. Edit anything that does not match your project. Delete lines that do not apply.
  3. Switch tabs for the other files, then copy or download each one into your repository.
  4. Run your agent on a small task and see what it gets wrong. Add one line per repeated mistake.

FAQ

Questions about the generator

What is an AGENTS.md file?

A plain Markdown file at the root of your repository that tells AI coding agents how to run, test and change your project. It has no required fields. Tools such as Cursor, GitHub Copilot and OpenAI Codex read it, and the closest AGENTS.md to the file being edited wins.

Does Claude Code read AGENTS.md?

Anthropic's docs say Claude Code reads AGENTS.md when there is no CLAUDE.md in the working directory or above it. The safest setup is a CLAUDE.md whose first line is @AGENTS.md, which is exactly what the CLAUDE.md tab here generates.

Is anything sent to a server?

No. The generator runs in your browser. It makes no network calls, uses no cookies or local storage, and has no analytics. Closing the tab discards what you typed.

Can I trust the generated commands?

Treat them as common defaults for the stack you pick. Check every command against your own package.json, Makefile or manifest before you rely on it. The AI Coding Agent Config Kit includes a prompt that makes your agent verify each command.

Will the agent always follow the file?

Not always. These files are guidance, not enforcement. Keep them short and specific, and use permission settings or hooks for anything that must never happen.
